# Codex Voice 3 v0.1.8

One-click access to the remote Mac desktop.

## Added

- **Ouvrir le partage d’écran** launches the macOS Screen Sharing app directly on the host already configured for the SSH tunnel.
- The shortcut remains available while Codex Voice is offline, making it useful for a locked session or after remotely unlocking FileVault.
- No hostname is hardcoded and no additional password is stored by Codex Voice.

Only the MacBook controller changes in this release; the v0.1.7 service already installed on the Mac mini remains compatible.
