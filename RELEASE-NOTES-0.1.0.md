# Codex Voice 3 v0.1.0

First public developer preview of the V3 rewrite.

## Included

- Native MacBook menu-bar controller.
- Passive Option-key interruption.
- Voice enable/disable and application volume.
- Persistent authenticated WebSocket state.
- Local macOS TTS runtime and user LaunchAgent installer.
- Multi-task ingestion, main-conversation orchestration and non-preemptive audio queue.
- Localhost + SSH security model with a private 256-bit token.

## Requirements

- macOS 13 or later.
- Apple Silicon for the attached prebuilt app.
- A Mac running Voice Local and reachable over SSH.

This archive is ad-hoc signed and not notarized. Verify the attached SHA-256 checksum before first launch. Installation and tunnel instructions are in the repository README.
